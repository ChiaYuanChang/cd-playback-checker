# 使用者 feedback 整合與驗收

## 現場證據與限制

2026-09-28 報告錄音長 2211.6 秒，只保留 2020.527–2208.527 秒的區段，前八首被判沒播；截圖顯示原始對齊進度已播。temp 沒有原始錄音與參考音檔，因此不能直接重新分析該場收音。

## 修改範圍

1. 對齊區段清理：比較同一錄音時間的映射，避免時鐘漂移被誤認為不同位置；冗餘映射改用較可靠映射保留已驗證的覆蓋，不能直接丟掉有效播放時間。保留真正跳針、重播和曲間空白判定。
2. 即時判定：進度與初步異常採用同一份 detector 結果，每五秒更新；即時位置持續更新。停止後完整重分析仍為最終結果。
3. 圖表：錄音與結果頁支援拖曳/縮放、全部顯示；錄音頁自動跟隨可關閉，手動拖曳/縮放自動停止跟隨。
4. 波形：錄音頁顯示對齊並校正振幅的錄音/參考包絡，每五秒更新；提供同方向疊圖與上下比較。未對齊部分保留空白，不能畫成確定無聲。
5. 靈敏度：0–100 拉桿，50 保留既有預設；提高靈敏度降低匹配、靜音與移動鎖定的門檻。測試片儲存預設，當次測試可覆寫並重新分析；錄音期間鎖定設定。報告記錄設定及實際門檻。
6. 收音診斷：顯示匹配分數、估計背景音與訊噪比；辨識不足時提示人工確認，不以分數代表播放品質。

## 驗收

- 長時間漂移、曲間空白不能刪掉前面的正常區段；正負漂移測試。
- 正常收音與低音量/低訊噪比案例；跳針、重播、靜音原有回歸仍通過。
- 原始錄音與串流停止後結果一致。
- 即時進度和異常共用 detector 結果；不把尚未播放的曲目判沒播。
- UI 手動範圍在新資料抵達後保留，跟隨/全部顯示能恢復；波形模式可切換且未對齊部分空白。
- 拉桿範圍、預設相容、profile round trip、錄音與既有檔案均採當次設定；JSON/HTML 包含設定。
- pytest、ruff、離屏 Qt 驗證並渲染 UI 檢查。Windows 麥克風/CD 現場與原始使用者 WAV 另需實機驗收。

### 操作與門檻

- 50：匹配 0.45、取得鎖定 0.55、靜音為背景 +6 dB、移動鎖定至少背景 +12 dB。
- 100：匹配 0.35、取得鎖定 0.45、靜音為背景 +3 dB、移動鎖定至少背景 +6 dB。
- 拉桿不變更短暫無聲的深度/長度門檻；提高靈敏度不代表故障判定更準。背景噪音或音訊處理吃掉聲音時仍需改善收音。
- 所有既有跳過、重播、卡住、靜音、中途停止與串流/離線一致性回歸通過。
